Sensitivity Analysis for Line-Source infinite reservoir with STIMTEC example.
results_v# folders are not to be erased: they contain SI and raw P(rw,t) results for analysis.

"Setting Morris Sampling.txt" contains the configuraiton of the sampling generation for current results

Optimisation folder contains workflow of optimisation protocol (pipeline)
run_* folders are results of optimisation protocol

In this (main) folder, the pressures are all processed in Pa (including optimisation). Some reports are in MPa (but the original data in Pa)
